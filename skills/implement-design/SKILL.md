# Implement a design

1. Read the design: layout, components, states, and spacing.
2. Map every element to an existing design-system component. Build a new component only when none fits.
3. Use design tokens for colors, spacing, and typography. Never hardcode them.
4. Run the app and compare a screenshot against the design. Fix differences.
5. For anything the design leaves unclear, comment on the Figma frame and ask the human.
