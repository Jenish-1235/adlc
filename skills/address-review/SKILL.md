# Address review comments

1. Fetch every unresolved review thread on the PR.
2. For each thread:
   - **Valid:** fix it and commit.
   - **Disagree or unclear:** reply with your reasoning or question. Leave the thread open.
3. Push.
4. For each fixed thread, reply with what changed and the commit, then resolve it.
