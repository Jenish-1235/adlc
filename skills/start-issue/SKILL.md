# Start an issue

1. Read the full issue, its comments, and linked docs.
2. If the acceptance criteria are missing or unclear, ask the human and stop.
3. Create the branch, named per the git policy.
4. Post a short plan as a comment on the issue.
5. Move the issue to In Progress.
