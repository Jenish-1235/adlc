# Start an issue

1. Confirm the issue is in Ready for Agent and doesn't have `AGENT: human-only`. If not, stop and tell the human.
2. Read the full issue, its comments, and linked docs.
3. If the acceptance criteria are missing or unclear, request input as the project-tracking policy describes, and stop.
4. Move the issue to In Progress.
5. Create the branch, named per the git policy.
6. Post a short plan as a comment on the issue.
